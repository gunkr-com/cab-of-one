# audit/

[English](README.md) | 한국어

원장(ledger)은 `audit/ledger/`에 있으며, 한 달에 JSON Lines 파일 하나(`YYYY-MM.jsonl`)를 씁니다. 생성기는 이 안에 아무것도 만들거나 지우지 않으며, `cab setup uninstall`은 이 폴더를 그대로 둡니다. 이 저장소의 이 폴더에는 실제 원장이 없습니다.

이 한국어판은 이 저장소에서 읽기 위한 것입니다. 생성된 프로젝트에는 영문 `audit/README.md`만 처음 적용할 때 한 번 만들어지며, 이 한국어판은 복사되지 않습니다.

## 누가 쓰는가

훅과 `cab` CLI가 파일 잠금 아래에서 원장에 줄을 추가합니다. 모델은 원장을 쓰지 않으며, 거부 규칙(deny rules)과 guard는 에이전트가 `audit/` 아래의 어떤 것도 편집하지 못하게 막습니다.

원장 줄에는 무엇보다 다음이 기록됩니다.

- **세션:** guard 자체 시험 결과를 포함한 세션 시작, 그리고 세션 종료.
- **guard 결정:** 관리 작업 호출에 대한 각 결정과 그 분류, 사유 코드.
- **쓰기:** 각 쓰기가 실행된 뒤의 정산(settlement). 종료 상태와 출력의 해시를 기록합니다. 출력 자체는 저장하지 않습니다.
- **변경 수명 주기:** intake, 검토 시작과 종료, 승인, 확인(acknowledgement), 재개(resume), 상태 변경, 스냅샷, 검증 결과.
- **설정:** 잠금이 허용하거나 보류한 설정 변경.

알려진 비밀 정보 패턴(토큰, JWT, 클라이언트 시크릿, 연결 문자열, 비밀번호 인자)은 줄을 쓰기 전에 가립니다(redact). 가리기는 패턴 기반이므로 특이한 형식은 놓칠 수 있습니다.

## 보장하지 않는 것

- **이 버전에는 해시 체인이 없습니다.** 파일을 쓸 수 있는 사람은 누구나 줄을 바꾸거나 지울 수 있으며, 하네스는 이를 감지하지 못합니다.
- **원장을 비공개 Git 저장소에 커밋하세요.** 그래야 이력이 원장을 고정합니다. 클라우드 동기화 폴더는 그렇게 하지 못합니다.
- **줄이 없다는 것은 모호합니다.** 아무 일도 없었다는 뜻일 수도 있고, 훅이 실행되지 않았다는 뜻일 수도 있습니다. `cab audit`는 원장의 세션 시작 줄을 Claude Code의 대화 기록(transcript)과 비교해 둘을 구분합니다. 다만 그 구분에는 소스 체크아웃의 `docs/threat-model.md`에 적힌 한계가 있습니다.

## 읽는 방법

- `cab status`는 열려 있는 변경을 요약합니다.
- `cab audit`는 하네스 밖에서 일어난 쓰기와 훅이 실행되지 않은 세션을 보고합니다.
- `cab audit metrics`는 원장 줄을 종류, 결정, 사유별로 셉니다.
