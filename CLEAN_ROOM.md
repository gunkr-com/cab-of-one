# Project background and provenance

English | [한국어](CLEAN_ROOM.ko.md)

cab-of-one is a portfolio project. It draws on the author's accumulated professional experience in IT operations: planning a change, getting the right approval, and verifying the result by re-reading the system. The author first adapted a development harness built around test-driven development to IT operations, then refined the approach through operational experience.

This version was newly implemented with AI assistance. Its inputs were the author's experience and knowledge, the author's own design specifications, and public technical documentation, such as the Claude Code and Python documentation. No code, prompts, configuration or operational data used in an employer's production environment were provided as implementation inputs.

All tenants, users, examples and test data are fictional or simulated and use the fictional Contoso company. The project's security and evaluation limits are described in the [README](README.md) and the [threat model](docs/threat-model.md).
